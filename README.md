# Habibi Cart for Windows and Mac

Habibi Cart keeps the **Habibi J1Gs** installer and operating-system application names so existing updates and saved data remain compatible.

**[Download the latest version](https://github.com/Habibi-Cart/habibi-j1gs-downloader/releases/latest)**

Open **Assets** on the download page and choose the installer for your computer:

- **Windows 10/11 (64-bit):** `Habibi-J1Gs-Setup-<version>.exe`
- **Mac (Apple Silicon or Intel):** `Habibi-J1Gs-<version>-mac-universal.dmg`

## Windows install and updates

Run the setup executable, then open Habibi J1Gs from the desktop or Start menu.
If you have an older copy, install this setup once to enable online updates.
After that, click **Check for Updates** in the app's sidebar. Your saved
profiles and settings stay on your PC.

## Mac install and updates

Open the DMG and drag **Habibi J1Gs** into **Applications**, then eject the
disk image. Mac builds support Apple Silicon and Intel. Mac releases are
installed manually: download the newer DMG and replace the app in Applications.
The app's profiles and settings stay on your Mac.

Unsigned Mac releases are not Apple-notarized. macOS may require approval in
**System Settings > Privacy & Security** after the first attempt to open the app.

## Publisher notices

Unsigned Windows installers may display an unknown-publisher or SmartScreen
notice. Unsigned Mac apps may require first-launch approval as described above.
Download releases only from this repository.
