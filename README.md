# Habibi Cart for Windows and Mac

Habibi J1Gs is now **Habibi Cart**.

**[Get Habibi Cart](https://habibicart.net/download)**

Sign in with Discord on the download page, then choose **Download for Windows** or **Download for Mac**. The Windows installer is for 64-bit Windows 10 or 11. The universal Mac installer supports Apple Silicon and Intel.

[Release history](https://github.com/Habibi-Cart/habibi-cart-downloader/releases)

## Windows install and updates

Run the setup executable, then open Habibi Cart from the desktop or Start menu.
If you already use Habibi J1Gs, click **Check for Updates** in its sidebar. You can also run the latest setup from the website. Your saved profiles and settings stay on the same PC.

## Mac install and updates

Open the DMG and drag the app into **Applications**, then eject the
disk image. Mac builds support Apple Silicon and Intel. Mac releases are
installed manually: download the newer DMG and replace the app in Applications.
The app's profiles and settings stay on your Mac.

Unsigned Mac releases are not Apple-notarized. macOS may require approval in
**System Settings > Privacy & Security** after the first attempt to open the app.

## Publisher notices

Unsigned Windows installers may display an unknown-publisher or SmartScreen
notice. Unsigned Mac apps may require first-launch approval as described above.
Use habibicart.net or the official GitHub releases above.
